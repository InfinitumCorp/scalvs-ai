# x402 agent payments

SCALVS.ai can charge AI agents and scripts a small fee per API request using
[x402](https://github.com/x402-foundation/x402) (HTTP 402 Payment Required, v2).
People using scalvs.app, the desktop app or the phone apps are never charged and see no change.

## How it works

- `api/_x402.js`, wired in `worker.js` around every `/api/*` route except connectors, OAuth and automations.
- A request counts as a person when the browser marks it same-origin or same-site (`Sec-Fetch-Site`),
  as a page navigation, or with an `Origin` of the site itself. Everything else is treated as an agent.
- An agent without payment gets `402` with a base64 `PAYMENT-REQUIRED` header (and the same JSON body):
  scheme `exact`, `X402_PRICE_USD` (default $0.001 = `1000` USDC units) on `X402_NETWORK` (default Base mainnet).
- An agent that retries with `PAYMENT-SIGNATURE` (or the legacy `X-PAYMENT`) is verified at the facilitator's
  `/verify`; the call runs; a successful response is settled at `/settle` and returned with `PAYMENT-RESPONSE`.
  Failed calls are not settled.
- The browser signals can be imitated, so this is a toll for honest agents, not access control.
  The per-IP rate limit still applies to everyone.

## Turning it on

It is on in code but does nothing until a receiving wallet is set:

| Setting | Default | |
|---|---|---|
| `X402_PAY_TO` | unset (off) | `0x…` wallet that receives USDC on Base |
| `X402_PRICE_USD` | `0.001` | price per request |
| `X402_NETWORK` | `eip155:8453` | Base mainnet; `eip155:84532` is Base Sepolia for testing |
| `X402_ASSET` | USDC on Base | token contract |
| `X402_FACILITATOR_URL` | `https://x402.org/facilitator` | must support the chosen network; Base mainnet needs a mainnet facilitator such as Coinbase CDP |
| `X402_FACILITATOR_API_KEY` | unset | secret, sent as a Bearer token if the facilitator needs one |
| `X402` | on | `off` disables it |

Set them as Worker vars or secrets (`wrangler secret put X402_PAY_TO`). Test on Base Sepolia first.
